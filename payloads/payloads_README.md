# 📨 Payloads

Mensagens de entrada (JSON) utilizadas nos testes dos laboratórios. Podem ser importadas diretamente no Postman ou usadas como referência.

| Arquivo | Cenário |
|---|---|
| `a1-entrada.json` | A1 — HTTP to Webhook |
| `a3-pedido.json` | A3 — Message Mapping |
| `a4-pedido.json` | A4 — Groovy Script |
| `b1-alto-valor.json` | B1 — Router (rota ALTO) |
| `b1-medio-valor.json` | B1 — Router (rota MÉDIO) |
| `b1-baixo-valor.json` | B1 — Router (rota BAIXO) |
| `b2-pedido.json` | B2 — Content Enricher |
| `b3-lote-itens.json` | B3 — Splitter (lote com 3 itens) |

> 💡 O A2 (Timer → API) não possui payload de entrada: é disparado por Timer.
